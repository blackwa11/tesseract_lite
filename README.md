## 🧩 Installation

1. Open Blender  
2. Go to: Edit → Preferences → Add-ons  
3. Click **Install**  
4. Select `tesseract_lite.py`  
5. Enable the addon  

---

## 🎮 Usage

1. Press **N** → open Sidebar  
2. Go to **4D Transform**  
3. Click **Create Tesseract**  
4. Press **Start**  
5. Adjust rotation parameters  

---

## ⚡ Features

- 4D hypercube (tesseract) visualization  
- Real-time 4D rotation  
- Projection from 4D to 3D  
- Mesh and Curve modes  
- Lightweight and fast  

---

## 🧠 Concept

This addon visualizes 4D geometry projected into 3D space.
