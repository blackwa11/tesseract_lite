# tesseract_lite

Lightweight Blender addon for real-time 4D tesseract projection and rotation.

---

## ⚡ Features
- 4D hypercube (tesseract)
- Real-time rotation in 4D space
- Mesh / Curve modes
- Lightweight and fast

---

## 🧩 Installation

1. Open Blender
2. Edit → Preferences → Add-ons
3. Click "Install"
4. Select `tesseract_lite.py`
5. Enable addon

---

## 🎮 Usage

- Press **N** → Sidebar
- Open **4D Transform**
- Click **Create Tesseract**
- Press **Start**
- Adjust rotation

---

## 🧠 Concept

This addon visualizes 4D geometry projected into 3D space.
